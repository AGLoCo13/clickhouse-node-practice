# 📊 ClickHouse Node.js Analytics Dashboard

A responsive web analytics dashboard built with **React**, **Node.js**, and **ClickHouse**, visualizing:
- 📈 Bitcoin average price over time (interactive chart with zoom & date filtering)
- 🏠 Top UK property sales by year (bar chart)

## 🧰 Tech Stack

| Frontend        | Backend     | Database   | Charts           |
|-----------------|-------------|------------|------------------|
| React (Vite)    | Node.js     | ClickHouse | Chart.js & Recharts |
| Bootstrap       | Express.js  |            | Responsive + Zoomable |

---

## 🚀 Getting Started

### Prerequisites

Make sure you have:

- Node.js (v18+)
- ClickHouse running (local or cloud)
- Git

---

### 🛠 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/your-repo-name.git
cd your-repo-name

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install
